# REST API of Products

A RESTful API project created as a practice exercise while learning how to build and work with APIs.

## 🎯 Purpose

The goal of this project was to learn and practice the fundamentals of RESTful API development, including:

- Handling HTTP requests and responses
- Working with CRUD operations
- Managing product data
- Understanding REST architecture
- Working with dynamic resources and IDs


## 📚 About the Project

This project was developed as a hands-on exercise to better understand backend development and the principles behind building RESTful APIs.

It focuses on managing product-related data through a simple and structured API.
